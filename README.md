Created a frontend dashboard that visualizes key insights about the dataset shared.
The app consist of dashboard/Home page with performance metrics and sidebar with list allowing to analyse data more deeply.
The application is built using ReactJS app (created via Vite) and deployed on Netlify - https://data-analytics-ev.netlify.app/home - The link is tested for accessibility.
To build the app -> Navigate to Frontend-Data-Analytics -> Npm run build -> will build dist folder which can be uploaded to netlify for deployment purpose(already done).
To run the application -> Install dependencies via npm install -> after that use npm run dev -> to run application locally.
I have used placeholder components/logos in header section, rest everything is functional on the web page.
